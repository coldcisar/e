# 🛒 E-commerce Web App

Aplicación web desarrollada como proyecto independiente, simulando un entorno real de negocio.

## Tecnologías
- Angular
- Node.js
- Express
- MySQL

## Funcionalidades
- Gestión de productos (CRUD)
- Carrito de compras
- Checkout
- Consumo de API REST
