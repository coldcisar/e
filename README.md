# 🛒 E-commerce Web Application

Aplicación web de **comercio electrónico** desarrollada como proyecto independiente, orientada a la gestión de productos y al proceso de compra de usuarios, simulando un entorno real de negocio y aplicando buenas prácticas de desarrollo web.

## 🚀 Descripción
El sistema permite administrar productos, gestionar un carrito de compras y realizar el proceso de checkout a través de una arquitectura cliente-servidor, integrando frontend y backend mediante APIs REST.

## 🛠 Tecnologías utilizadas
- Angular
- TypeScript
- Node.js
- Express
- MySQL
- HTML
- CSS

## ⚙️ Funcionalidades principales
- Gestión de productos (CRUD)
- Carrito de compras con persistencia de datos
- Cálculo automático de totales
- Proceso de checkout
- Consumo y desarrollo de APIs REST
- Integración frontend y backend

## 🧱 Arquitectura
- Frontend desarrollado en **Angular**
- Backend desarrollado en **Node.js y Express**
- Comunicación mediante **APIs REST**
- Base de datos relacional **MySQL**

## 📂 Estado del proyecto
Proyecto funcional en desarrollo, enfocado en demostrar conocimientos en desarrollo **Full Stack**, lógica de negocio e integración de servicios.
